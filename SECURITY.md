# Security Policy

## Supported versions

Crewbase runs as a single hosted instance at [crewbase.dev](https://crewbase.dev). Only the latest version, on the `main`
branch, receives security fixes.

## Reporting a vulnerability

Please report security problems privately, not in a public GitHub issue.

- Email the address shown on [crewbase.dev/help](https://crewbase.dev/help) with the subject **“Security report”**, or
- Use GitHub’s **Report a vulnerability** button on this repository, if it’s enabled.

Please include:

- What you found and where (page, API route or file)
- Steps to reproduce it
- What someone could do with it
- Any browser console or network logs that help

We’ll reply as soon as we can, usually within a few days. Please give us reasonable time to fix the issue before sharing it
publicly, and don’t access, change or delete other people’s data while testing. Testing done in good faith under these
rules is welcome.

## Scope

In scope: crewbase.dev and this repository’s code. Out of scope: Roblox, Discord, Vercel, Neon and other third-party
services, which have their own programs.

Crewbase is based on [Firefli](https://github.com/TeamFirefli/firefli). Issues that also affect the original project may be
worth reporting upstream too.
